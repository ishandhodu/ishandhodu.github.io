# How this site is built

- Static site only: HTML, CSS, and a little plain JavaScript. No frameworks,
  no build step, no npm, no server.
- If a request needs a server, a database, logins, payments, or a working
  contact form, stop and tell me, then add it to the Later list in PRD.md.
- Build only the pages/sections listed in PRD.md. Ask before adding a page
  or a section.
- Styles live in css/styles.css. Define colors, spacing, and fonts as custom
  properties in a :root block and reuse them, rather than repeating values.
- File and folder names: lowercase, hyphens, no spaces.
- Content in About/Experience/Projects starts as placeholder text until real
  content is provided — don't invent specific job titles, dates, or project
  details as if they were fact.
